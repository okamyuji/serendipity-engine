# グラフ可視化仕様書

## 概要

ノート間のコネクションをインタラクティブなグラフとして可視化します。React Flow を使用して、ノードとエッジで構成されるナレッジグラフを表示し、ユーザーが視覚的にナレッジベースを探索できます。

## 機能要件

### FR-GRAPH-001: グラフデータの取得

ノードとエッジのデータを取得します。

入力として、以下のパラメータを受け取ります。

- limit: ノードの最大数（任意、デフォルト100件）
- min_strength: エッジの最小強度（任意、デフォルト0.5）

処理の流れは以下の通りです。

1. ユーザーのアクティブなノートを取得します
2. 指定された強度以上のコネクションを取得します
3. ノードデータを生成します
4. エッジデータを生成します

出力として、nodes 配列と edges 配列を含む JSON を返します。

### FR-GRAPH-002: ノードデータの構造

各ノードには以下の情報が含まれます。

- id: ノートIDの文字列表現
- type: ノードタイプ（常に "note"）
- data: ノードの詳細情報
  - label: ノートのタイトル
  - project: プロジェクト名
  - projectColor: プロジェクトの色
  - tags: タグ名の配列
  - accessCount: アクセス回数
  - lastAccessed: 最終アクセス日時（ISO8601形式）
  - createdAt: 作成日時（ISO8601形式）
  - hasChunks: チャンクの有無

### FR-GRAPH-003: エッジデータの構造

各エッジには以下の情報が含まれます。

- id: エッジID（"e{source_id}-{target_id}" 形式）
- source: 起点ノードのID
- target: 終点ノードのID
- type: エッジタイプ（"smoothstep"）
- data: エッジの詳細情報
  - strength: コネクションの強度（0.0〜1.0）
  - connectionType: コネクションタイプ（semantic / explicit / temporal / tag_based）
  - aiSuggested: AI提案フラグ
  - confirmed: 確認済みフラグ

### FR-GRAPH-004: グラフの表示

React Flow を使用してグラフを表示します。

表示機能は以下の通りです。

- ノードをドラッグして移動できます
- ズームイン・ズームアウトができます
- パン（画面移動）ができます
- ノードをクリックして詳細を表示できます
- エッジをクリックしてコネクション情報を表示できます

レイアウトの特徴は以下の通りです。

- 自動レイアウトアルゴリズムを使用します
- プロジェクトごとにノードをグループ化します
- 強いコネクションほど近くに配置します

### FR-GRAPH-005: ノードのスタイリング

ノードの視覚的表現を定義します。

スタイルの詳細は以下の通りです。

- プロジェクトの色をノードの背景色に使用します
- 選択されたノードは枠線が強調されます
- チャンクがないノードは半透明で表示されます
- アクセス回数が多いノードは大きく表示します

### FR-GRAPH-006: エッジのスタイリング

エッジの視覚的表現を定義します。

スタイルの詳細は以下の通りです。

- 強度に応じて線の太さを変更します
- AI提案で未確認のエッジはアニメーションします
- 確認済みのエッジは緑色で表示します
- コネクションタイプに応じて線のスタイルを変更します

### FR-GRAPH-007: フィルタリング

表示するノードとエッジをフィルタリングします。

フィルタの種類は以下の通りです。

- プロジェクトでフィルタ
- タグでフィルタ
- 作成日でフィルタ
- アクセス回数でフィルタ
- コネクションの強度でフィルタ

処理の詳細は以下の通りです。

- フィルタはクライアント側で適用します
- 複数のフィルタを組み合わせられます
- フィルタ状態は URL パラメータで保持します

### FR-GRAPH-008: ミニマップ

全体のグラフ構造を俯瞰できるミニマップを表示します。

機能の詳細は以下の通りです。

- 現在の表示領域をハイライトします
- ミニマップをクリックして移動できます
- プロジェクトの色でノードを表示します

### FR-GRAPH-009: コントロールパネル

グラフ操作のためのコントロールを提供します。

機能の詳細は以下の通りです。

- ズームイン・ズームアウトボタン
- フィットビューボタン（全体を表示）
- ロックボタン（ノードの移動を固定）
- レイアウトリセットボタン

## データモデル

### connections テーブル

各カラムの詳細は以下の通りです。

- id: bigint型、主キー
- source_note_id: bigint型、NOT NULL制約、外部キー（notesテーブルを参照）
- target_note_id: bigint型、NOT NULL制約、外部キー（notesテーブルを参照）
- connection_type: string型、DEFAULT "semantic"、コネクションタイプ
- strength: float型、DEFAULT 0.5、強度（0.0〜1.0）
- ai_suggested: boolean型、DEFAULT false、AI提案フラグ
- confirmed: boolean型、DEFAULT false、確認済みフラグ
- explanation: text型、説明文
- created_at: datetime型、NOT NULL制約、作成日時
- updated_at: datetime型、NOT NULL制約、更新日時

インデックスの設定は以下の通りです。

- source_note_id, target_note_id の一意複合インデックス
- strength のインデックス
- connection_type のインデックス

制約の詳細は以下の通りです。

- source_note と target_note は同じユーザーに属する必要があります
- source_note_id と target_note_id は異なる必要があります

## フロントエンド実装

### コンポーネント構造

以下のコンポーネントで構成されます。

- GraphView: メインコンテナ
- NoteNode: カスタムノードコンポーネント
- ConnectionEdge: カスタムエッジコンポーネント
- GraphControls: コントロールパネル
- GraphFilters: フィルタUI

### 状態管理

以下の状態を管理します。

- nodes: ノードの配列
- edges: エッジの配列
- selectedNode: 選択中のノード
- filters: フィルタ設定
- viewport: 表示領域の状態

### レイアウトアルゴリズム

以下のアルゴリズムを使用します。

- Force-directed layout: 力学モデルに基づく配置
- Hierarchical layout: 階層構造に基づく配置
- Circular layout: 円形配置

デフォルトは Force-directed layout です。

## API エンドポイント

### GET /api/v1/graph

グラフデータを取得します。

クエリパラメータは以下の通りです。

- limit: ノード数の上限
- min_strength: エッジの最小強度

レスポンス形式は以下の通りです。

```json
{
  "nodes": [
    {
      "id": "1",
      "type": "note",
      "data": {
        "label": "ノートタイトル",
        "project": "プロジェクト名",
        "projectColor": "#6366f1",
        "tags": ["タグ1", "タグ2"],
        "accessCount": 10,
        "lastAccessed": "2024-01-08T10:00:00Z",
        "createdAt": "2024-01-01T00:00:00Z",
        "hasChunks": true
      }
    }
  ],
  "edges": [
    {
      "id": "e1-2",
      "source": "1",
      "target": "2",
      "type": "smoothstep",
      "data": {
        "strength": 0.85,
        "connectionType": "semantic",
        "aiSuggested": true,
        "confirmed": false
      }
    }
  ]
}
```

## パフォーマンス考慮事項

### データ量の制限

以下の制限を設けています。

- デフォルトで最大100ノードを表示します
- 強度0.5未満のエッジは除外します
- ページネーションは実装しません（フィルタリングで対応）

### レンダリングの最適化

以下の最適化を実施しています。

- React Flow の仮想化機能を使用します
- ノードの再レンダリングを最小化します
- メモ化を活用します

### データの取得

以下の最適化を実施しています。

- 初回ロード時のみサーバーから取得します
- フィルタリングはクライアント側で実行します
- キャッシュを活用します

## インタラクション

### ノードのクリック

ノードをクリックすると以下の動作をします。

- ノート詳細モーダルを表示します
- 関連するエッジをハイライトします
- 隣接ノードを強調表示します

### エッジのクリック

エッジをクリックすると以下の動作をします。

- コネクション情報を表示します
- 確認ボタンを表示します（AI提案の場合）
- 削除ボタンを表示します

### ノードのドラッグ

ノードをドラッグすると以下の動作をします。

- 位置を変更します
- レイアウトを再計算します
- 変更を保存します（オプション）

## アクセシビリティ

以下のアクセシビリティ対応を実施します。

- キーボードナビゲーションをサポートします
- スクリーンリーダー対応のラベルを提供します
- 十分なコントラスト比を確保します
- フォーカスインジケーターを表示します
